# Love Cake Animation 🎂

A Python animation where a cake is built out of "I love you" written in dozens of languages. Candles rise and light up, get blown out one by one, and the cake slowly fades away.

## Requirements

- Python 3
- tkinter (included with Python on Windows)

**Optional:** to display Urdu, Arabic, Hebrew and Persian text correctly:

```
pip install arabic-reshaper python-bidi
```

## How to run

1. Download `cake.py`
2. Open a terminal in that folder and run:

```
python cake.py
```

## Controls

- `Space`: restart the animation
- `Esc`: close the window

## Customize

- Edit the `PHRASES` list at the top of `cake.py` to change the text on the cake
- Change `CANDLES` to use more or fewer candles
- Set `LOOP = False` to play the animation only once
